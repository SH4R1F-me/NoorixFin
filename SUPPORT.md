# Support policy

NoorixFin is community-supported software without a response-time or uptime
SLA.

- Use GitHub Discussions for setup questions and design proposals.
- Use GitHub Issues for reproducible defects and accepted feature work.
- Use private vulnerability reporting for security concerns.
- For self-host incidents, include the NoorixFin version/commit, deployment
  method, redacted Compose status, failing health check, and relevant logs.

Maintainers may close requests that cannot be reproduced, fall outside Reading
A, disclose sensitive data, or lack enough information after a reasonable
follow-up. Never post `.env` files, database dumps, tokens, or personal financial
records.
